## Reading a diagnostic

Every diagnostic is printed on two lines with no indent ([AD-17](../decisions/0001-foundation.md#ad-17-authoring-experience)):

```text
path:line:col: error[FB0102]: message
help: what to do about it
```

- `path` is relative to the repository root (`/`-separated).
- `line` and `col` are 1-based (`1:1` for a finding about a whole file), and `col` counts Unicode code points.
- `severity` is `error` or `warning`. Codes whose catalogue severity is `strict` (`FB0118`, `FB0230`, `FB0320`) are reported as `warning` by default and as `error` under `fieldbook check --strict`.
- Diagnostics are sorted by `(path, line, col, code)` with one blank line between findings, followed by any `note: text` lines and the summary line `N errors, M warnings` (`clean` when both are zero).

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Clean (zero errors; warnings do not change the exit code) |
| `1` | Findings (at least one error) |
| `2` | Usage error (invalid command-line arguments or configuration refusal) |
| `3` | I/O or operational failure |
