# Questions for IT

The owner sends all 39 questions below at the first IT contact. Each answer changes a design decision. A line is enough for most. Until an answer arrives, Fieldbook works to the default shown, and a default is never treated as permission.

Part A (IT-1 through IT-11) is the standing list of questions about allowlisting, assets, signing, AI, data, transfer and policy. Part B (IT-12 through IT-26) is the list of questions that came from the design of the Tier-0 files, the Handoff step and backup. Part C (IT-27 through IT-39) is about the product's own AI and the company data it may hold: the endpoint and its key, the route, the policy file, the labels, the journal, who holds the store when the owner leaves, disposal, the credential for a connector and the features of the operating system that read page text. Questions about a company identity for a later multi-user application and about hosting a server wait for that application and are not asked now. Tiers: Tier 0 is files only, Tier 1 is a signed `fieldbook.exe` installed by IT, Tier 2 is an MSI, only if IT requires one.

Where a question names the program, it says which build and tool version it is about. The first edition holds files only and no program. Tool versions 0.1.x are the silent build: `check`, `build`, `search`, `backup`, `restore` and the audit journal. The AI build is a separate program from tool version 0.2.0 and is not in the first edition. `fieldbook mcp`, the policy-file reader, `audit export` and `ai status` are from tool version 0.2.0, `fieldbook chat` (feature `bridge`) is from tool version 0.3.0, and the company store, `sync`, `label` and the signed program are from R2.

IT-9 comes first. Without it nothing reaches the laptop, and Fieldbook proposes no channel of its own. IT-11 is asked at the first contact, before any request for an executable. IT-26 and IT-28 through IT-31 are asked before the signed program is installed. IT-27 and IT-32 through IT-39 go with the Day 60 to 75 intake request, with IT-2. Until they are answered the floor applies, so company text that arrives is `unlabelled`, or `marked` when it carries a banner; it stays in the company store for the owner's own use and goes to no destination, except that `unlabelled` text may go to a backup folder that the owner recorded as company storage. At E1 the Tier-0 copy step works to its default; at R2 the program's target needs the answer.
