## Purpose

Shows, under 13 CFR 121.402 [@CL-MKT-0375], which size standard a concern must meet, who designates the NAICS code, and how multiple award contracts and their orders are handled.

## The rule

| Field | Value |
|---|---|
| Instrument | Not established. |
| Codified citation | Not established. |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Not established. |
| Applies to | Concerns offering on a solicitation that specifies a NAICS code [@CL-MKT-0375] |

A concern must not exceed the size standard for the NAICS code specified in the solicitation, and the contracting officer must specify the size standard in effect on the date the solicitation is issued [@CL-MKT-0375]. The procuring agency contracting officer, or an authorized representative, designates the NAICS code and size standard, selecting the single code that best describes the principal purpose of the product or service being acquired [@CL-MKT-0376]. Except for multiple award contracts, a solicitation must contain only one NAICS code and only one size standard [@CL-MKT-0377].

A procurement is generally classified according to the component that accounts for the greatest percentage of contract value [@CL-MKT-0378]. Acquisitions for supplies must be classified under the appropriate manufacturing or supply NAICS code, not under a Wholesale Trade or Retail Trade NAICS code [@CL-MKT-0546].

The NAICS code assigned to a procurement and its corresponding size standard is final unless timely appealed to SBA's Office of Hearings and Appeals, or unless SBA assigns an NAICS code or size standard as provided in a later paragraph of the section [@CL-MKT-0547].

## How it works

For a multiple award contract, the contracting officer takes one of two listed routes [@CL-MKT-0526; @CL-MKT-0380]. The first is to assign one code and size standard to the solicitation, but only if that code will also best describe the principal purpose of each order [@CL-MKT-0379]. The other is to divide the solicitation into discrete categories and assign each discrete category the single code and size standard that best describes the principal purpose of the goods or services to be acquired under that category [@CL-MKT-0380; @CL-MKT-1839]. A concern must then meet the size standard for each category for which it seeks an award as a small business [@CL-MKT-0381]. Each order against a multiple award contract takes a single NAICS code, and that code must be one included in the underlying contract [@CL-MKT-0382].

## Worked example

Synthetic example. The numbers are made up.

A solicitation names one NAICS code, and its size standard is 600 employees. A concern has 700 employees, counting its affiliates. The concern exceeds the standard for that code, so it does not meet the size standard on this solicitation.

## Never confuse

Choosing the NAICS code and its size standard is a different step from deciding on what date a concern's size is measured, which [When a concern's size status is measured](../taxonomy/mkt-sba-size-measurement-date.md) covers. It is also different from an appeal of the code to SBA's Office of Hearings and Appeals, because the assigned code is final unless timely appealed [@CL-MKT-0547]. The linked card, [Size standards, NAICS codes and appeals](../taxonomy/mkt-size-standards-and-naics-codes.md), covers the wider picture. Whether a firm that resells supplies counts as small is a separate test, set out in [How a nonmanufacturer qualifies as a small business on a supply contract](../taxonomy/mkt-sba-nonmanufacturer-qualification.md).
