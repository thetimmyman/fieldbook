## Purpose

Governs the decomposition of control account scope, schedule, and budget into executable work packages and planning packages.

## The rule

| Field | Value |
|---|---|
| Instrument | DoD EVMS Interpretation Guide [@CL-PRG-0227] |
| Codified citation | Not established. |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Not established. |
| Applies to | Control accounts in an earned value management system [@CL-PRG-0227] |

The contractor must plan the authorized scope, schedule, and budget into work packages and/or planning packages [@CL-PRG-0227]. Budgets are determined in terms of dollars, hours, or other measurable units such that the sum of all work package and planning package budgets equals the control account budget [@CL-PRG-0228]. Distributing all control account budgets to either work packages or planning packages ensures the Performance Measurement Baseline is planned at an executable level that aligns with how meaningful performance measurements will be achieved [@CL-PRG-0230].

## How it works

Work packages reflect the expected way the work is to be done and are a distinguishable subdivision of a control account, assignable to a single program organizational element [@CL-PRG-0229]. When authorized control account work scope cannot be planned in the near-term, a planning package is used for holding the scope, schedule, and budget until the work is detail planned into work packages [@CL-PRG-0231]. The planning package is time-phased with the known schedule requirements and is detail planned into work packages at the earliest practicable point before any work is performed on the scope contained in the planning package [@CL-PRG-0232]. The sum of all work package budgets plus planning package budgets within control accounts equals the budgets authorized for those control accounts [@CL-PRG-0233].

## Worked example

Synthetic example. The numbers are made up.

A control account has an authorized budget of 500,000 across a 12-month period. The manager plans months 1 through 4 into two discrete work packages valued at 150,000 each (300,000 total). The remaining 200,000 covering months 5 through 12 is placed in a planning package. At month 3, rolling wave planning converts the 200,000 planning package into three discrete work packages before far-term work begins.

## Never confuse

The sum of all work package budgets plus planning package budgets within control accounts equals the budgets authorized for those control accounts [@CL-PRG-0233]. For future effort that cannot practically be identified to a control account, it is permissible to establish a Summary Level Planning Package above the control account level [@CL-PRG-0216]. When authorized control account work scope cannot be planned in the near-term, a planning package is used for holding the scope, schedule, and budget until the work is detail planned into work packages, and is detail planned into work packages at the earliest practicable point before any work is performed on the scope contained in the planning package [@CL-PRG-0231; @CL-PRG-0232]. See [Earned value management system requirement](prg-evms-requirement.md).

The guideline on the performance measurement criteria for each work package is covered in [performance measurement criteria for each work package](prg-evms-guideline-10-performance-measurement-criteria.md).
