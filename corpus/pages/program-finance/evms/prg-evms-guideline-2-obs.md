## Purpose

Sets out what the guide requires of a program organizational structure, and where it places the program manager's authority.

## The rule

| Field | Value |
|---|---|
| Instrument | DoD EVMS Interpretation Guide, not a codified instrument [@CL-PRG-0158] |
| Codified citation | Not established. |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Not established. |
| Applies to | Programs that must name the organizations responsible for the authorized work [@CL-PRG-0159] |

The guideline asks the contractor to identify the program organizational structure, including the major subcontractors, that is responsible for accomplishing the authorized work, and to define the organizational elements where work will be planned and controlled [@CL-PRG-0159]. Hierarchical, unique alpha-numeric coding of that structure results in the organizational breakdown structure [@CL-PRG-0160].

When the contractor designates the internal organization that manages the program, it must assign a program manager with enough authority and responsibility to ensure the authorized work is performed [@CL-PRG-0161]. The manager assigned to subcontractor work must carry full responsibility for that work [@CL-PRG-0162]. A single organizational structure exists that contains all the organizational elements defined by the organizational breakdown structure, including major subcontractors and inter-company work, as necessary to execute the contract [@CL-PRG-0163].

## How it works

The contractor identifies the program organizational structure, including the major subcontractors, and defines the organizational elements where work will be planned and controlled [@CL-PRG-0159]. Coding that structure produces the organizational breakdown structure, which is defined with uniquely defined nomenclature [@CL-PRG-0160; @CL-PRG-0164]. The guideline also requires a program manager with sufficient authority and responsibility, and a manager with full responsibility for subcontractor work [@CL-PRG-0161; @CL-PRG-0162]. The intersection of the lowest level work breakdown structure element and the organizational breakdown structure is where control accounts are established [@CL-PRG-0167].

## Worked example

Synthetic example. The numbers are made up.

A program has 5 operating divisions and names 18 organizational elements, of which 3 are major subcontractors. Work is planned and controlled at those elements and the program manager holds written authority over the whole scope. The answer is that the structure is complete, because every piece of contract scope, subcontractor scope included, maps to one of the 18 named elements.

## Never confuse

The organizational breakdown structure assigns responsibility for work, while the work breakdown structure defines the work itself [@CL-PRG-0159; @CL-PRG-0153]. The two are not one-to-one, because for management control there may be multiple control accounts within one organizational element, and one or more responsible organizations may support a single element of work [@CL-PRG-0170]. Naming a program manager is also not the same as building the structure, because the guideline asks for a manager with sufficient authority and responsibility and for a single structure that contains all the organizational elements [@CL-PRG-0161; @CL-PRG-0163].

## Company calibration

Who in each organizational element owns the program estimate at completion, and whether that manager's authority over the forecast is written down [@CL-PRG-0161; @Q-010]
