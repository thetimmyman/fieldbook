## Purpose

Sets out what the guide requires of a program organizational structure, and where it places the program manager's authority.

## The rule

| Field | Value |
|---|---|
| Instrument | DoD EVMS Interpretation Guide, not a codified instrument [@CL-PRG-0158] |
| Codified citation | Not established. |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Not established. |
| Applies to | Programs that must name the organizations responsible for the authorized work [@CL-PRG-0159] |

The guideline asks the contractor to identify the program organizational structure, including the major subcontractors, that is responsible for accomplishing the authorized work, and to define the organizational elements where work will be planned and controlled [@CL-PRG-0159]. Hierarchical, unique alpha-numeric coding of that structure results in the organizational breakdown structure [@CL-PRG-0160].

When the contractor designates the internal organization that manages the program, it must assign a program manager with enough authority and responsibility to ensure the authorized work is performed [@CL-PRG-0161]. The manager assigned to subcontractor work must carry full responsibility for that work [@CL-PRG-0162]. A single organizational structure exists that contains all the organizational elements defined by the organizational breakdown structure, including major subcontractors and inter-company work, as necessary to execute the contract [@CL-PRG-0163].

## How it works

The contractor identifies the program organizational structure, including the major subcontractors, responsible for accomplishing the authorized work and defines the organizational elements where work will be planned and controlled [@CL-PRG-0159]. The hierarchical alpha-numeric unique coding of the organization structure results in the Organizational Breakdown Structure (OBS), which is defined with uniquely defined nomenclature [@CL-PRG-0160; @CL-PRG-0164]. When designating the internal organization responsible for managing the program efforts, the contractor must assign a program manager with sufficient authority and responsibility to ensure the performance of the authorized work, and the manager assigned to subcontractor work must have full responsibility for the authorized work [@CL-PRG-0161; @CL-PRG-0162]. The intersection of the lowest level work breakdown structure element and the organizational breakdown structure is the point at which control accounts are established [@CL-PRG-0167].

## Worked example

Synthetic example. The numbers are made up.

A program has 5 operating divisions and names 18 organizational elements, of which 3 are major subcontractors. Work is planned and controlled at those elements and the program manager holds written authority over the whole scope. The answer is that the structure is complete, because every piece of contract scope, subcontractor scope included, maps to one of the 18 named elements.

## Never confuse

The program organizational structure, including the major subcontractors, is responsible for accomplishing the authorized work and defines the organizational elements where work will be planned and controlled, while the work breakdown structure is a product-oriented, hierarchical breakdown of the program requirements that includes all program elements (e.g., hardware, software, services, data, or facilities) [@CL-PRG-0159; @CL-PRG-0153]. For management control purposes, there may be one or more responsible organizations supporting a single work breakdown structure element or multiple control accounts within one organizational breakdown structure element driven by scope and exit criteria (i.e., completion of the effort) [@CL-PRG-0170; @CL-PRG-0072]. When designating the internal organization responsible for managing the program efforts, the contractor must assign a program manager with sufficient authority and responsibility to ensure the performance of the authorized work, and a single organizational structure exists that contains all of the organizational elements as defined by the organizational breakdown structure, including major subcontractors and inter-company work, necessary to execute the contract [@CL-PRG-0161; @CL-PRG-0163].
