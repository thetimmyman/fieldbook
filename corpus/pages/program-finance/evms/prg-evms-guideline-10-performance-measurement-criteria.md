## Purpose

Shows how the guide expects a contractor to pick a performance measurement technique for each work package, so that progress is measured objectively [@CL-PRG-0252].

## The rule

| Field | Value |
|---|---|
| Instrument | DoD EVMS Interpretation Guide, Guideline 10 [@CL-PRG-0251] |
| Codified citation | Not established. |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Not established. |
| Applies to | Programs that operate an earned value management system [@CL-PRG-0252] |

Each work package carries an objective measurement criterion chosen to fit the way the work is expected to be accomplished, and only effort that cannot be measured is treated as level of effort [@CL-PRG-0252]. Level of effort is confined to activities with no practicable, measurable output that could be planned and measured discretely at the work package level [@CL-PRG-0253].

Where a long-duration work package is unavoidable, interim milestones that model measurable technical accomplishment are required [@CL-PRG-0255]. Apportioned effort should be used for supporting work that ties directly to a discrete technical activity [@CL-PRG-0256]. If the contractor chooses to use it, the system documentation must cover the technique and the factor that establishes the relationship [@CL-PRG-0257].

## How it works

The control account manager assesses each assigned work package and looks for a discrete way to measure progress towards its completion [@CL-PRG-0254]. The criterion is objective and set per work package, consistent with how the work is expected to be accomplished [@CL-PRG-0252]. Level of effort earns value only as time passes, so it never shows a schedule variance and always equals the budgeted cost for work scheduled [@CL-PRG-0258]. Earned value for discrete material items may be claimed on receipt, inspection and acceptance, provided the items go into use within a reasonable time or are identified to a serially numbered end item [@CL-PRG-0260]. The program evaluation and review technique cost formula is a non-discrete material method [@CL-PRG-0764]. It computes BCWP as (ACWP/EAC) x BAC and needs the estimate at completion evaluated and updated every month [@CL-PRG-0764; @CL-PRG-0259]. It is appropriate only for high-quantity, low-value, low-risk items where measurement is impracticable [@CL-PRG-0763].

## Worked example

Synthetic example. The numbers are made up.

A work package to build a test fixture is budgeted at 40,000 and planned to finish in three months. The manager finds a discrete measure, because the fixture is a definable product accepted at a single milestone, so the package is planned as discrete rather than level of effort. The fixture is accepted in month three and the full 40,000 is earned in that period.

## Never confuse

Level of effort is not apportioned effort. Level of effort earns value with the passage of time and never carries a schedule variance, while apportioned effort is for supporting work that ties directly to a discrete technical activity and, if the contractor uses it, the system documentation must cover the technique and the factor that establishes the relationship [@CL-PRG-0258; @CL-PRG-0256; @CL-PRG-0257].

The guideline on planning work packages and planning packages is covered in [plan work packages and planning packages](prg-evms-guideline-9-work-and-planning-packages.md), and the guideline on assessing progress against the plan is covered in [assessing progress against the plan](prg-evms-guideline-14-assess-progress.md).

## Company calibration

Which work packages the company measures as level of effort, and whether the system description documents each technique and the evidence behind it. [@Q-037]
