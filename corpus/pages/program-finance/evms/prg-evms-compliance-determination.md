## Purpose

Shows how compliance of an earned value management system is judged, what the contractor must document and demonstrate, and how subcontractor work is treated.

## The rule

| Field | Value |
|---|---|
| Instrument | DoD EVMS Interpretation Guide, not a codified instrument [@CL-PRG-0627] |
| Codified citation | Not established. |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Not established. |
| Applies to | Contractors with a contractual earned value requirement, and primes that integrate subcontractor data [@CL-PRG-0629; @CL-PRG-0630] |

Compliance is judged in three steps. The first is to assess whether the System Description adequately documents the processes and procedures that support how the system meets the intent of the 27 guidelines [@CL-PRG-0627]. The second is to evaluate the contractor's ability to demonstrate the implementation as described in the System Description and supplemental procedures, and the third is to ensure the system provides timely, accurate, reliable and auditable data [@CL-PRG-0628]. When contractually required, contractors must demonstrate compliance with the 27 guidelines, regardless of the reporting requirements in the contractual data requirements list [@CL-PRG-0629].

The contractor maintains a stand-alone System Description or a set of integrated process descriptions that describe its approach to a compliant system [@CL-PRG-0633]. The prime must document and demonstrate an effective way to manage the integrating subcontractor's data in its own system [@CL-PRG-0630]. Subcontractors include inter-company work agreements whose planning, execution and reporting of scope and schedule are independent of the prime [@CL-PRG-0631], but inter-company work scope and schedule whose daily operations are under the prime's direct management control and are directly integrated into the prime effort are not considered a subcontract [@CL-PRG-0632]. The criteria for telling the two apart should be documented in the contractor's system description [@CL-PRG-0804].

## How it works

The three steps are the document check, the demonstration and the data test, in the order the guide lists them [@CL-PRG-0627; @CL-PRG-0628]. For subcontractor work the prime must also show how that data is brought into its own system [@CL-PRG-0630]. Whether inter-company work counts as a subcontract turns on its independence from the prime and on criteria set out in the system description [@CL-PRG-0631; @CL-PRG-0632; @CL-PRG-0804]. Who makes the final compliance call is on [the Interpretation Guide page](prg-evms-interpretation-guide.md).

## Worked example

Synthetic example. The numbers are made up.

A prime passes an earned value requirement down to one outside supplier. It also has an affiliate whose daily work is run by the prime's own managers and built into the prime schedule. The prime treats the supplier as a subcontractor and sets up a method to bring its data into the prime system. The affiliate is not treated as a subcontract. The answer: one subcontractor to integrate, and one directly managed team.

## Never confuse

Demonstrating compliance is not the same as having a reporting line in the contract: contractors must demonstrate compliance regardless of the reporting requirements [@CL-PRG-0629]. The dollar thresholds that decide which contracts need a system are a separate matter; see [Earned value management system requirement](prg-evms-requirement.md).

## Company calibration

Whether the company's System Description is current, has been shown in practice, and covers subcontractors. [@Q-037]
