## Purpose

Shows when an offeror must give its CAGE code, how codes are obtained, and the codes needed for owners and for subcontractors with access to classified information.

## The rule

| Field | Value |
|---|---|
| Instrument | Codified FAR [@CL-SUP-0566] |
| Codified citation | FAR 52.204-16 [@CL-SUP-0566] |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Final [@CL-SUP-0566] |
| Applies to | Offerors, where the provision is used as prescribed in FAR 4.1804(a) [@CL-SUP-0699] |

The offeror shall provide its CAGE code with its offer with its name and location address or otherwise include it prominently in its proposal, and the code must be for that name and location address [@CL-SUP-0566]. The CAGE code is required prior to award [@CL-SUP-0566]. The offeror must not delay submission of the offer pending receipt of a CAGE code [@CL-SUP-0567].

## How it works

For entities located in the United States or its outlying areas, a CAGE code is an identifier assigned by the DLA CAGE Branch to identify a commercial or government entity by unique location [@CL-SUP-0700]. For entities outside the United States and its outlying areas, the definition covers an identifier assigned by a member of the North Atlantic Treaty Organization or by the NATO Support and Procurement Agency [@CL-SUP-0701]. An offeror in the United States or its outlying areas that has no code is assigned one by the DLA CAGE Branch as a part of the SAM registration process [@CL-SUP-0702]. When a code is required for the immediate owner or the highest-level owner, the offeror shall obtain the respective code from that entity to supply it to the Government [@CL-SUP-0568]. If the solicitation includes the Security Requirements clause, a subcontractor requiring access to classified information shall be identified with a CAGE code on the DD Form 254 [@CL-SUP-0703], and each location of subcontractor performance listed there is required to reflect a corresponding unique CAGE code unless the work is performed at a Government facility, in which case the agency location code is used [@CL-SUP-0569].

## Worked example

Synthetic example. The numbers are made up.

An offeror in the United States has no CAGE code when the solicitation closes. It registers in SAM and submits its offer on time without waiting.

Answer: submitting without waiting is correct. The offeror gets its code through the SAM registration, and the code is required before award.

## Never confuse

A CAGE code identifies an entity by unique location, so a code belongs to a name and location address [@CL-SUP-0700; @CL-SUP-0566]. A code needed for an owner is not the offeror's own code: the offeror obtains it from that owner [@CL-SUP-0568]. Owner reporting is on the [Ownership or control of offeror](sup-ownership-or-control-of-offeror.md) card.
