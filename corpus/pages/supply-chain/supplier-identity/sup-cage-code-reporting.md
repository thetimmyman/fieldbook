## Purpose

Shows when an offeror must give its CAGE code, how codes are obtained, and the codes needed for owners and for subcontractors with access to classified information.

## The rule

| Field | Value |
|---|---|
| Instrument | Codified FAR and codified DFARS [@CL-SUP-0566; @CL-SUP-4119] |
| Codified citation | FAR 52.204-16 [@CL-SUP-0566]; DFARS 204.1870 [@CL-SUP-4119]; FAR 2.101 [@CL-SUP-9611; @CL-SUP-9612; @CL-SUP-9613] |
| RFO citation | RFO FAR 52.204-90(d) [@CL-SUP-3615; @CL-SUP-3616]; RFO FAR 52.204-91 [@CL-SUP-3618; @CL-SUP-3619]; RFO FAR 52.204-7(b)(3) [@CL-SUP-3620; @CL-SUP-3621]; RFO FAR 52.240-92(e) [@CL-SUP-3624; @CL-SUP-3625]; RFO FAR 52.204-16 is reserved [@CL-SUP-3614]; RFO FAR 2.101 [@CL-SUP-9614; @CL-SUP-9615; @CL-SUP-9616] |
| Edition date | Not established. |

| Applies to | Offerors, where the provision is used as prescribed in FAR 4.1804(a) [@CL-SUP-0699] |

The offeror shall provide its CAGE code with its offer with its name and location address or otherwise include it prominently in its proposal, and the code must be for that name and location address [@CL-SUP-0566]. The CAGE code is required prior to award [@CL-SUP-0566]. The offeror must not delay submission of the offer pending receipt of a CAGE code [@CL-SUP-0567].

## How it works

For entities located in the United States or its outlying areas, a CAGE code is an identifier assigned by the DLA CAGE Branch to identify a commercial or government entity by unique location [@CL-SUP-0700]. For entities outside the United States and its outlying areas, the definition covers an identifier assigned by a member of the North Atlantic Treaty Organization or by the NATO Support and Procurement Agency, that the DLA CAGE Branch records and maintains in the CAGE master file [@CL-SUP-0701; @CL-SUP-9727]. The FAR definitions section gives the same two alternatives in its definition of a CAGE code [@CL-SUP-9611; @CL-SUP-9612; @CL-SUP-9613], and the RFO text of FAR 2.101 has them word for word [@CL-SUP-9614; @CL-SUP-9615; @CL-SUP-9616]. The last sentence of the FAR definition says this type of code is known as a NATO CAGE (NCAGE) code [@CL-SUP-9613; @CL-SUP-9642], and the RFO text has it word for word [@CL-SUP-9616; @CL-SUP-9643]. An offeror in the United States or its outlying areas that has no code is assigned one by the DLA CAGE Branch as a part of the SAM registration process [@CL-SUP-0702]. When a code is required for the immediate owner and/or the highest-level owner by FAR 52.204-17 or 52.212-3(p), the offeror shall obtain the respective code from that entity to supply it to the Government [@CL-SUP-0568]. If the solicitation includes the Security Requirements clause, a subcontractor requiring access to classified information shall be identified with a CAGE code on the DD Form 254 [@CL-SUP-0703], and each location of subcontractor performance listed there is required to reflect a corresponding unique CAGE code unless the work is performed at a Government facility, in which case the agency location code is used [@CL-SUP-0569]. The defense supplement says to follow the procedures and guidance at PGI 204-1870 concerning Commercial and Government Entity (CAGE) codes and CAGE file maintenance, and the text names no official [@CL-SUP-4119].

Under the RFO text, DoD contracting officers use the RFO FAR part 52 text in place of the codified text from February 1, 2026 [@CL-CMP-9760] [@CL-CMP-9762]. The RFO text lists 52.204-16 as reserved [@CL-SUP-3614], and the offeror's CAGE code paragraph is in 52.204-90, which the offeror completes if it will not have an active SAM registration when it submits its offer [@CL-SUP-3615]. Paragraph (d)(1) of 52.204-90 says the offeror shall provide its CAGE code with its offer with its name and location address or otherwise include it prominently in its offer, and that the code shall be for that name and location address [@CL-SUP-3616; @CL-SUP-0566]. The sentences that follow in (d)(1) tell the offeror to insert the word CAGE before the code and say the offeror may obtain a code as the table indicates, so (d)(1) prints no sentence that the code is required prior to award and none about not delaying the offer [@CL-SUP-3617; @CL-SUP-0566; @CL-SUP-0567]. The RFO definitions of a CAGE code are in 52.204-91 and say the same in substance [@CL-SUP-3618; @CL-SUP-3619; @CL-SUP-0700; @CL-SUP-0701]. The RFO text of 52.204-7(b)(3)(ii) keeps the rule that an offeror in the United States or its outlying areas with no code is assigned one by the DLA CAGE Branch as a part of the SAM registration process [@CL-SUP-3620; @CL-SUP-0702]. For owners, 52.204-7(b)(3)(iii) says the offeror shall get the CAGE code of any immediate and/or highest-level owner to provide as part of the registration, and does not print the codified reference to FAR 52.204-17 or 52.212-3(p) [@CL-SUP-3621; @CL-SUP-0568]; 52.204-90(d)(2) lists the owners and predecessors whose codes and legal business names the offeror provides [@CL-SUP-3622; @CL-SUP-3623]. For classified work, 52.240-92(e) says a subcontractor requiring access to classified information shall be identified with a CAGE code on the DD Form 254, in a clause that applies to the extent that the contract involves access to information classified Confidential, Secret, or Top Secret, where the codified sentence depends on the solicitation including FAR 52.204-2 [@CL-SUP-3624; @CL-SUP-3626; @CL-SUP-0703]. It keeps the rule that each location of subcontractor performance listed on the DD Form 254 reflects a unique CAGE code unless the work is at a Government facility, in which case the agency location code is used [@CL-SUP-3625; @CL-SUP-0569]. The RFO text of 52.204-90 says to insert the provision as prescribed in 4.208(c)(1), where the codified provision is used as prescribed in 4.1804(a) [@CL-SUP-3627; @CL-SUP-0699].

## Worked example

Synthetic example. The numbers are made up.

An offeror in the United States has no CAGE code when the solicitation closes. It registers in SAM and submits its offer on time without waiting.

Answer: submitting without waiting is correct. The offeror gets its code through the SAM registration, and the code is required before award. Under the RFO text, the code paragraph in 52.204-90 is completed if the offeror will not have an active SAM registration when it submits its offer [@CL-SUP-3615].

## Never confuse

A CAGE code identifies an entity by unique location, so a code belongs to a name and location address [@CL-SUP-0700; @CL-SUP-0566]. Under the codified text the CAGE code is required prior to award [@CL-SUP-0566], while RFO 52.204-90(d)(1) prints no such sentence and applies on the condition in its lead-in [@CL-SUP-3617; @CL-SUP-3615]. A code needed for an owner is not the offeror's own code: the offeror obtains it from that owner [@CL-SUP-0568]. Owner reporting is on the [Ownership or control of offeror](sup-ownership-or-control-of-offeror.md) card.
