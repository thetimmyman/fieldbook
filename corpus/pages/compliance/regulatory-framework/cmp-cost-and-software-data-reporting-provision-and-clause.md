## Purpose

Shows how the DoD pairs the cost and software data reporting provision with its clause, and which version of the clause a major defense acquisition program uses at each value.

## The rule

| Field | Value |
|---|---|
| Instrument | Codified DFARS [@CL-CMP-7867] |
| Codified citation | DFARS 234.7101 [@CL-CMP-7867] |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Final [@CL-CMP-7867] |
| Applies to | Solicitations that include the cost and software data reporting clause, and solicitations and contracts for major defense acquisition programs within the stated value ranges [@CL-CMP-7867; @CL-CMP-7871; @CL-CMP-7872] |

The basic or the alternate of the provision at 252.234-7003, Notice of Cost and Software Data Reporting System, is to be used in any solicitation that includes the basic or the alternate of the clause at 252.234-7004 [@CL-CMP-7867]. The basic provision is to be used when the solicitation includes the basic clause, and the alternate I provision when it includes the alternate I clause [@CL-CMP-7868; @CL-CMP-7869].

The basic or the alternate of the clause at 252.234-7004, Cost and Software Data Reporting System, is to be used in solicitations that include major defense acquisition programs, as the two following paragraphs provide [@CL-CMP-7870]. The basic clause is to be used in solicitations and contracts for major defense acquisition programs that exceed $50 million [@CL-CMP-7871]. The alternate I clause is to be used in solicitations and contracts for major defense acquisition programs with a value equal to or greater than $20 million but less than or equal to $50 million, when so directed by the program manager with the approval of the OSD Deputy Director, Cost Assessment [@CL-CMP-7872].

## How it works

The provision and the clause are chosen as a pair, so whichever version of the clause the solicitation includes decides which version of the provision is used [@CL-CMP-7867; @CL-CMP-7868; @CL-CMP-7869]. The clause itself is used in solicitations that include major defense acquisition programs [@CL-CMP-7870]. Above the higher value line, the paragraph states only the value test for the basic clause [@CL-CMP-7871]. Between the two value lines, inclusive of both, the alternate I clause needs two steps: a direction from the program manager and the approval of the OSD Deputy Director, Cost Assessment [@CL-CMP-7872]. For a value below the lower line, the section prescribes neither version of the clause [@CL-CMP-7871; @CL-CMP-7872]. The section sets no deadline.

## Worked example

Synthetic example. The numbers are made up.

A solicitation for a major defense acquisition program is valued at 60,000,000 dollars. That exceeds 50,000,000 dollars, so the basic clause is to be used, and the solicitation carries the basic provision [@CL-CMP-7871; @CL-CMP-7868].

A solicitation for a second program is valued at 30,000,000 dollars, and the program manager directs the alternate I clause with the approval of the OSD Deputy Director, Cost Assessment. The solicitation includes the alternate I clause and so carries the alternate I provision [@CL-CMP-7872; @CL-CMP-7869].

A third program is valued at exactly 50,000,000 dollars. The basic clause needs a value that exceeds 50,000,000 dollars, so it is not prescribed on value alone. The alternate I clause can be used, because 50,000,000 dollars is within the range, if the program manager directs it with the approval [@CL-CMP-7871; @CL-CMP-7872].

A fourth program is valued at 30,000,000 dollars and the program manager gives no direction, so this section does not call for the alternate I clause [@CL-CMP-7872].

## Never confuse

The provision and the clause are separate documents: the provision at 252.234-7003 is a notice of the reporting system, and the clause at 252.234-7004 is the cost and software data reporting clause [@CL-CMP-7867]. The alternate I provision is not interchangeable with the basic provision, because each follows the version of the clause in the solicitation [@CL-CMP-7868; @CL-CMP-7869]. This section selects which versions go into a solicitation; it does not set the reporting content of each version. For the reporting content itself, see [Cost and software data reporting](../business-systems/cmp-dfars-cost-and-software-data-reporting.md); for commercial treatment of weapon systems, see [Weapon system commerciality and CSDR](cmp-weapon-system-commerciality-and-csdr.md).
