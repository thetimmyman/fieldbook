## Purpose

Shows how the DoD pairs the cost and software data reporting provision with its clause, and which version of the clause a major defense acquisition program uses at each value.

## The rule

| Field | Value |
|---|---|
| Instrument | Codified DFARS [@CL-CMP-7867] |
| Codified citation | DFARS 234.7101 [@CL-CMP-7867] |
| RFO citation | Not established. |
| Edition date | Not established. |
| Text status | Final [@CL-CMP-7867] |
| Applies to | Solicitations that include the cost and software data reporting clause, and solicitations and contracts for major defense acquisition programs within the stated value ranges [@CL-CMP-7867; @CL-CMP-7871; @CL-CMP-7872] |

The basic or the alternate of the provision at 252.234-7003, Notice of Cost and Software Data Reporting System, is to be used in any solicitation that includes the basic or the alternate of the clause at 252.234-7004 [@CL-CMP-7867]. The basic provision is to be used when the solicitation includes the basic clause, and the alternate I provision when it includes the alternate I clause [@CL-CMP-7868; @CL-CMP-7869].

The basic or the alternate of the clause at 252.234-7004, Cost and Software Data Reporting System, is to be used in solicitations that include major defense acquisition programs, as follows [@CL-CMP-7870]. The basic clause is to be used in solicitations and contracts for major defense acquisition programs that exceed $50 million [@CL-CMP-7871]. The alternate I clause is to be used in solicitations and contracts for major defense acquisition programs with a value equal to or greater than $20 million but less than or equal to $50 million, when so directed by the program manager with the approval of the OSD Deputy Director, Cost Assessment [@CL-CMP-7872].

## How it works

The basic provision is used when the solicitation includes the basic clause, and the alternate I provision when it includes the alternate I clause [@CL-CMP-7868; @CL-CMP-7869], and the provision is used in any solicitation that includes the clause [@CL-CMP-7867]. The clause itself is used in solicitations that include major defense acquisition programs [@CL-CMP-7870]. The basic clause is used in solicitations and contracts for major defense acquisition programs that exceed $50 million [@CL-CMP-7871]. For a value equal to or greater than $20 million but less than or equal to $50 million, the alternate I clause is used when so directed by the program manager with the approval of the OSD Deputy Director, Cost Assessment [@CL-CMP-7872].

## Worked example

Synthetic example. The numbers are made up.

A solicitation for a major defense acquisition program is valued at 60,000,000 dollars. That exceeds 50,000,000 dollars, so the basic clause is to be used, and the solicitation carries the basic provision [@CL-CMP-7871; @CL-CMP-7868].

A solicitation for a second program is valued at 30,000,000 dollars, and the program manager directs the alternate I clause with the approval of the OSD Deputy Director, Cost Assessment [@CL-CMP-7872]. The solicitation includes the alternate I clause and so carries the alternate I provision [@CL-CMP-7869].

A third program is valued at exactly 50,000,000 dollars. The basic clause is for programs that exceed 50,000,000 dollars, and 50,000,000 dollars does not exceed that figure [@CL-CMP-7871]. The alternate I clause is for a value equal to or greater than 20,000,000 dollars but less than or equal to 50,000,000 dollars, so 50,000,000 dollars is within that range, when so directed by the program manager with the approval of the OSD Deputy Director, Cost Assessment [@CL-CMP-7872].

A fourth program is valued at 30,000,000 dollars, within the range for the alternate I clause, but the program manager has given no direction, so the direction that paragraph (b)(2) attaches to the alternate I clause is absent [@CL-CMP-7872].

## Never confuse

The provision at 252.234-7003 is the Notice of Cost and Software Data Reporting System, and the clause at 252.234-7004 is Cost and Software Data Reporting [@CL-CMP-7867]. The basic provision is used when the solicitation includes the basic clause, and the alternate I provision when it includes the alternate I clause [@CL-CMP-7868; @CL-CMP-7869]. The reporting content itself is covered in [Cost and software data reporting](../business-systems/cmp-dfars-cost-and-software-data-reporting.md), and commercial treatment of weapon systems is covered in [Weapon system commerciality and CSDR](cmp-weapon-system-commerciality-and-csdr.md).
