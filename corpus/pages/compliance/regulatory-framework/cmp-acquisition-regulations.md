## Purpose

Explains which rule text governs a DoD contract today: the codified FAR and DFARS, the overhaul model text, or a class deviation.

## The rule

The FAR sets the acquisition rules for executive agencies, and the DFARS supplements it for DoD. The Revolutionary FAR Overhaul rewrites FAR parts as model text, which agencies adopt through class deviations before the rewrite is codified. DoD lists the class deviations it has issued for the overhaul, each with its supplement part, and tells users to apply the overhaul definitions where they exist [@S-0021-v1]. For DoD work the governing text is therefore often the deviation, not the codified text. Each Fieldbook claim records both citations, and where the two texts differ, a conflict is recorded.

## How it works

Start from the contract: its clauses, their dates and any deviation it names. Check whether a class deviation covers the part in question, read the deviation text, and compare it with the codified text. A clause card shows both citations side by side with the date each took effect. When the contract was awarded before a deviation, read its clauses as written; when it is new, expect the deviation text.

## Worked example

Synthetic example. The numbers are made up.

A new DoD solicitation asks for certified data above 12 million, while a reference book from last year quotes a lower figure. The book predates the deviation, so the solicitation's figure is current, and the book is marked as possibly stale.

## Never confuse

A class deviation authorises different text for a class of contracts now; a proposed rule is a draft open for comment; a final rule changes the codified regulation. The overhaul model text is a drafting source, binding only once a deviation or final rule adopts it. See the threshold changes in [Rule changes to know before Day 1](cmp-brief-rule-changes.md).
